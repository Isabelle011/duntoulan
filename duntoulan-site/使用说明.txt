墩头蓝网站 · 使用说明
=================================

一、怎么打开
  双击 index.html 即可在浏览器中打开（推荐 Chrome / Edge）。
  8 个页面通过顶部导航互相跳转，无需安装任何软件、无需联网。

二、怎么拷走 / 分享
  必须拷贝【整个 duntoulan-site 文件夹】，不能只拷 html 文件。
  文件夹内部结构请不要打乱、不要改名：
     index.html 等 8 个页面
     css/style.css        全站样式（改颜色、字号只动这里）
     images/              全部图片（换图就替换这里的同名文件）
     图片替换对照表.html   每张图对应哪一页、什么内容、建议尺寸

三、怎么换图片
  1) 打开 images 文件夹，找到要换的文件名（见 图片替换对照表.html）
  2) 把自己的照片改成完全相同的文件名（含 .jpg 后缀）
  3) 拖进 images 文件夹，选择"替换目标中的文件"
  4) 浏览器按 Ctrl + F5 强制刷新
  注意：比例尽量接近原图，单张建议 1MB 以内。

四、怎么改文字
  用记事本 / VS Code 打开对应 html 文件，搜索要改的文字直接替换即可。
  每个板块前都有注释标记，例如 <!-- ═══ ② 文化简介 ═══ -->。

五、关于字体
  标题字体思源宋体（Noto Serif SC）通过 Google Fonts 加载：
  联网时效果最佳；断网时自动回落到系统宋体，页面依然正常显示。

六、注意
  - 页脚电话、邮箱、地址目前为占位内容（XXXX），请替换为真实信息。
  - 联系页的留言表单为静态展示，暂不能真正接收留言；
    如需收集留言，可接入云服务（数据库 + 邮件通知）。
  - 浏览器需允许本地文件互跳（默认即可），若导航点不动，
    请改用 Chrome，或把文件夹放到本地服务器环境运行。
